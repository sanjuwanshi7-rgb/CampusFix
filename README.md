# 🚀 CampusFix

CampusFix is a full-stack campus issue reporting and management system that helps students report campus problems and allows administrators to track and update their status.

## ✨ Features

### 👩‍🎓 Student Dashboard

- View total reported issues
- View Pending, In Progress and Resolved issues
- Report new campus issues
- Select issue category, location and priority
- View recently submitted reports
- Track the status of submitted issues

### 👨‍💼 Admin Dashboard

- View all reported campus issues
- View total reports and status statistics
- Update issue status
- Manage Pending, In Progress and Resolved reports
- Monitor campus issues in one place

## 🔄 How It Works

1. A student opens the CampusFix dashboard.
2. The student submits a campus issue.
3. The issue is stored in the system.
4. The admin views the reported issue.
5. The admin updates the issue status.
6. The updated status is reflected on the student dashboard.

## 🎯 Problem Solved

CampusFix provides a centralized platform for reporting and managing campus issues, making it easier for students to report problems and for administrators to track their resolution.
